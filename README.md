
# Pytho Loops and Functions

## Description
This assignment includes three Python programs covering while loops, for loops, control statements, and functions.

## Programs

### 1. Number Guessing Game
- Generates a random number between 1 and 10 using the random module.
- Uses a while loop to allow three guessing attempts.
- Implements break, continue, and else statements.
- Provides feedback for correct, incorrect, and out-of-range guesses.

### 2. Multiplication Table Generator
- Takes a number as user input.
- Uses a for loop and range() function.
- Generates and displays the multiplication table from 1 to 10.

### 3. BMI Calculator
- Defines a user-defined function named calculate_bmi().
- Uses parameters and return statements.
- Takes weight and height as user input.
- Calculates and displays Body Mass Index (BMI).

## Concepts Covered
- While Loop
- For Loop
- Control Statements (break, continue, pass, else)
- Functions
- Parameters and Arguments
- Return Statement
- Random Module
- Conditional Statements
